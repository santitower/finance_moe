## Architecture

Phase 1: 5 experts run independently (5 calls)
Phase 2: Synthesizer detects conflicts (1 call)
Phase 3: Per-conflict debate — 4 rounds max x 4 calls = up to 48 calls
Phase 4: Synthesizer generates final report (1 call)
Total: 60 calls max, ~53 available for debate

## Two-Stage Debate Protocol

Each debate round = 4 LLM calls:
1. Expert A reasoning (thinking ENABLED)
2. Expert A JSON extraction (thinking DISABLED)
3. Expert B reasoning (thinking ENABLED)
4. Expert B JSON extraction (thinking DISABLED)

Checkpoint every 4 rounds to decide if debate should stop.
